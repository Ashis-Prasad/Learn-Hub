# LearnHub 📚

LearnHub is a simple and responsive educational website designed to provide students with an organized platform to explore learning resources, discover courses, and enhance their knowledge.

## 🚀 Features

- Clean and user-friendly interface
- Multiple webpages with consistent design
- Responsive layouts for different screen sizes
- Organized course and learning sections
- Easy navigation between pages
- Modern styling and visual elements

## 🛠️ Technologies Used

- HTML5– Website structure
- CSS3– Styling and layouts

## 💻 Getting Started

To run this project locally:

1. Clone the repository:

   git clone https://github.com/Ashis-Prasad/Learn-Hub.git


2. Navigate to the project folder:

   cd Learn-Hub

3. Open index.html in your browser.

This project was developed to strengthen my frontend development skills and gain practical experience in building multi-page websites using HTML and CSS.
